# Cinejoy Native iOS

This is a native SwiftUI iOS starter, not a WebView wrapper.

The GitHub Actions workflow creates an unsigned iOS IPA artifact.

## Build

1. Upload the files to your GitHub repository.
2. Open Actions.
3. Select "Build Cinejoy Native iOS".
4. Select "Run workflow".
5. Download the "CinejoyNative-IPA" artifact.
6. Sign it with your own Apple account/signing method before installing.

The current starter demonstrates native UI and an authorized TMDB catalogue API connection. Playback should only be connected to video sources you are authorized to access.
